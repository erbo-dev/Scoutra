# Scoutra Editorial Landing Page

React/Vite editorial landing page for Scoutra. Its visual rhythm was studied against the public Tonsser homepage; the implementation is independent, uses Scoutra-specific copy and locally supplied Kazakhstan youth-football media, and has no Tonsser runtime dependencies. This is a visual foundation, not a functioning assessment product.

## Commands

- `npm run dev` — start the local Vite server.
- `npm run lint` — run Oxlint.
- `npm run build` — type-check and create the production build.
- `npm run preview` — preview the production build.
